# Forma — Personal Performance Journal

A mobile-first React fitness journal. No backend or account required. Workout history, exercise setup, measurements, nutrition and recovery are stored in this browser's localStorage.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL.

## Important
- Export a JSON backup from Settings regularly. Local browser data is not cloud-synced and may be cleared by browser/device changes.
- Historical workouts start empty. Dashboard metrics derive only from entries you create.
- This initial version includes the editable exercise library, four templates, per-set logging, history, CSV/JSON export/import, measurements, meal estimates and recovery check-ins.
